# Attendance ProxyProof

An Android attendance management app built with **Kotlin** and **Android Studio**, using Bluetooth Low Energy (BLE) for device communication.

### Features
- PIN-based authentication
- Local attendance storage
- Bluetooth Low Energy communication
- User profiles

### Tech Stack
- Kotlin
- Android Studio
- BLE / GATT
- SharedPreferences

### Getting Started
Clone the repository and open the project in Android Studio:

```bash
git clone https://github.com/natalyalibin/Attendance-ProxyProof-.git
```

Sync Gradle and run the app on a compatible Android device.
